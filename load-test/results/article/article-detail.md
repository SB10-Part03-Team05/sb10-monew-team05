# 뉴스 기사 단건 조회 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: GET /api/articles/{articleId}
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소
- 10개의 기사 ID 중 랜덤으로 선택하여 요청

## 결과 분석
- 에러율 0%, 모든 기준 통과로 매우 안정적인 서비스 제공
- 평균 응답시간 10.07ms로 300명에서도 빠른 응답 속도 유지
- p95 16.27ms, p99 25.96ms로 모든 사용자가 26ms 이내 응답 받음
- 최대 응답시간 80.08ms로 전체적으로 안정적인 성능 유지
