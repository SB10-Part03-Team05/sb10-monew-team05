# 뉴스 기사 단건 조회 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: GET /api/articles/{articleId}
- 테스트 시간: 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소
- 10개의 기사 ID 중 랜덤으로 선택하여 요청

## 성능 지표 결과

| 지표 | 결과 | 기준 | 통과 여부 |
|------|------|------|---------|
| 평균 응답시간 (avg) | 18.41ms | - | - |
| p95 응답시간 | 21.68ms | 500ms | ✅ |
| p99 응답시간 | 33.61ms | 1000ms | ✅ |

## 결과 분석
- 평균 응답시간 18.41ms로 빠른 응답 속도
- 에러율 0%로 안정적인 서비스 제공
- p95 21.68ms로 95%의 사용자가 22ms 이내 응답 받음
- p99 33.61ms로 99%의 사용자가 34ms 이내 응답 받음
- 뉴스 기사 목록 조회(avg 18.97ms)와 유사한 응답 속도
