# 뉴스 기사 목록 조회 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: GET /api/articles
- 테스트 시간: 51초
- 최대 동시 사용자: 50명

## 테스트 시나리오
- 0 ~ 10초: 10명으로 증가
- 10 ~ 40초: 50명으로 증가
- 40 ~ 50초: 0명으로 감소

## 결과 분석
- 평균 응답시간 3.21ms로 매우 빠른 응답 속도
- 에러율 0%로 안정적인 서비스 제공
- p95 23.88ms로 95%의 사용자가 24ms 이내 응답 받음
- p95 3.96ms, p99 4.87ms로 모든 사용자가 5ms 이내 응답 받음
- 파라미터 없이 단순 목록 반환이라 빠른 응답 속도를 가지는 것이라 예상
