# 뉴스 기사 목록 조회 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: GET /api/articles
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 10초: 10명으로 증가
- 10 ~ 40초: 50명으로 증가
- 40 ~ 50초: 0명으로 감소

## 결과 분석
- 평균 응답시간 4.48ms로 300명에서도 매우 빠른 응답 속도 유지
- 에러율 0%로 안정적인 서비스 제공
- p95 23.88ms로 95%의 사용자가 24ms 이내 응답 받음
- p95 5.99ms, p99 10.53ms로 모든 사용자가 11ms 이내 응답 받음
- 파라미터 없이 단순 목록 반환이라 부하가 증가해도 빠른 응답 속도 유지
