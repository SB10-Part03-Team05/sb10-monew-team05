# 뉴스 기사 목록 조회 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: GET /api/articles
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소

## 결과 분석
- 에러율 0%로 서버는 안정적으로 동작
- 평균 응답시간 268.23ms로 50명 테스트(18.97ms) 대비 약 14배 증가
- p95 788.43ms로 허용 기준(500ms) 초과 → 병목 발생
- 500ms 초과 요청 1,342건 발생 (전체의 11%)
