# 관심사 목록 조회 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: GET /api/interests
- 테스트 시간: 50초
- 최대 동시 사용자: 50명

## 테스트 시나리오
- 0 ~ 10초: 10명으로 증가
- 10 ~ 40초: 50명으로 증가
- 40 ~ 50초: 0명으로 감소

## 결과 분석
- 평균 응답시간 9.14ms로 매우 빠른 응답 속도
- 에러율 0%로 안정적인 서비스 제공
- p95 14.48ms로 95%의 사용자가 15ms 이내 응답 받음
- p99 32.64ms로 99%의 사용자가 33ms 이내 응답 받음
- 최대 응답시간 479.5ms로 일부 요청에서 지연 발생하나 허용 범위 내
