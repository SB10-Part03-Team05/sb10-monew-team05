# 관심사 등록 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: POST /api/interests
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소

## 성능 지표 결과

| 지표 | 결과 | 기준 | 통과 여부 |
|------|------|------|---------|
| 평균 응답시간 (avg) | 1.61s | - | - |
| p95 응답시간 | 4.89s | 500ms | ❌ |
| p99 응답시간 | 5.08s | 1000ms | ❌ |
| RPS (초당 요청 수) | 44.13 | - | - |
| 에러율 | 30.99% | 1% 미만 | ❌ |
| 전체 요청 수 | 3,162 | - | - |

## 결과 분석
- 유사도 검사 시 비관적 락(Pessimistic Lock) 적용으로 인해 300명 동시 요청 시 락 경합 발생
- 평균 응답시간 1.61s로 매우 느린 응답 속도
- 에러율 30.99%로 유사도 검사에서 409 에러 다수 발생

## 병목 지점
- 비관적 락으로 인한 동시 요청 처리 지연
- 관심사 등록은 실제 서비스에서 빈번하게 발생하는 작업이 아니므로 허용 가능한 수준으로 판단
- 단, 동시 다발적 등록 요청 시 성능 저하 발생 가능
