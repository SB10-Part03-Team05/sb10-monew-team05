# 사용자 정보 수정 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: PATCH /api/users/{userId}
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소

## 결과 분석
- 에러율 0%, 모든 기준 통과로 매우 안정적인 서비스 제공
- 평균 응답시간 5.42ms로 300명에서도 매우 빠른 응답 속도 유지
- p95 7.65ms, p99 12.09ms로 99%의 사용자가 13ms 이내 응답 받음
- 최대 응답시간 98.92ms로 전체적으로 안정적인 성능 유지

## 한계점
- 사용자 수정 API는 본인만 수정 가능한 인가 정책으로 인해, 단일 사용자 ID로 부하를 집중하는 구조가 불가피함
- 이로 인해 동일 레코드에 대한 동시 업데이트 경합이 발생하여 일반적인 PATCH 처리량보다 낮은 성능 수치를 보일 수 있음
- 실제 서비스에서는 사용자별 요청이 분산되므로, 본 테스트 결과는 최악의 시나리오(핫스팟)에 가까운 값으로 해석하는 것이 적절함
