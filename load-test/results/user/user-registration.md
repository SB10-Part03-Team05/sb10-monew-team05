# 회원가입 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: POST /api/users
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소
- 중복 방지를 위해 랜덤 이메일 생성하여 요청
