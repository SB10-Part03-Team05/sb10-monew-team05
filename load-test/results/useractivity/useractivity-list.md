# 사용자 활동내역 조회 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: GET /api/user-activities/{userId}
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소

## 결과 분석
- 에러율 0%로 서버는 안정적으로 동작
- 평균 응답시간 698.02ms로 매우 느린 응답 속도
- p95 1.91s, p99 1.96s로 허용 기준 초과 -> 심각한 병목 발생
- 500ms 초과 요청 2,321건 발생 (전체의 약 50%)
