# 댓글 수정 API 부하테스트 결과

## 테스트 환경
- 도구: k6
- 대상 API: PATCH /api/comments/{commentId}
- 테스트 시간: 약 71초
- 최대 동시 사용자: 300명

## 테스트 시나리오
- 0 ~ 30초: 50명으로 증가
- 30 ~ 60초: 300명으로 증가
- 60 ~ 70초: 0명으로 감소
- 5개의 댓글 ID 중 랜덤으로 선택하여 요청

## 성능 지표 결과

| 지표 | 결과 | 기준 | 통과 여부 |
|------|------|------|---------|
| 평균 응답시간 (avg) | 9.08ms | - | - |
| p95 응답시간 | 15.24ms | 500ms | ✅ |
| p99 응답시간 | 50.75ms | 1000ms | ✅ |
| RPS (초당 요청 수) | 106.85 | - | - |
| 에러율 | 27.21% | 1% 미만 | ❌ |
| 전체 요청 수 | 7,567 | - | - |

## 결과 분석
- 응답시간 기준은 모두 통과로 서버 성능 자체는 양호
- 에러율 27.21%는 5개의 댓글 ID에 300명이 동시에 수정 요청 시 충돌 발생

## 한계점
- 부하테스트 특성상 소수의 댓글 ID에 다수의 요청이 집중되어 충돌 발생
- 실제 서비스에서는 사용자마다 자신의 댓글을 수정하므로 실제 부하 환경과 차이 있음
- 성공 응답(200) 기준 avg 8.51ms, p95 13.37ms로 양호한 수준

## 병목 지점
